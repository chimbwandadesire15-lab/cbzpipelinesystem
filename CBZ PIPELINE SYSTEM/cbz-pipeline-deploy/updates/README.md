# updates/

Drop new `.html` versions here for version history before promoting to `docs/index.html`.

Naming convention: `CBZ_Pipeline_vX.Y_YYYY-MM-DD.html`

Example workflow:
1. Generate new version via `pycharm_updater/build.py`
2. Copy the output here as an archive: `updates/CBZ_Pipeline_v3.1_2025-07-01.html`
3. Also copy to `docs/index.html` (this is what GitHub Pages serves)
4. Commit and push
